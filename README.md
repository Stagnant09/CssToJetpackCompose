A library that bridges CSS styling syntax with Jetpack Compose. It allows developers to apply familiar CSS declarations — including colors, typography, padding, and borders — directly to composable functions via a @CssStyle annotation and a runtime parser that resolves them into native Modifier and TextStyle objects.
